# 超级编导完整平台复刻 Spec

## 需求（Requirements）

- 背景：参考站是“超级编导”AI 内容创作平台，公开资源显示它包含无限画布、工作流、创意模板库和画布广场等入口。
- 目标：搭建一个本地可运行的完整平台前端复刻，保留工作台密度、蓝色主色、创作链路和主要页面关系。
- 范围：桌面优先，同时适配窄屏；首页、AI 创作、无限画布、工作流、创意模板库、画布广场、素材库，以及账户/团队/套餐相关页面。首阶段以本地演示数据跑通页面和交互，后续再接真实后端。
- 验收标准：
  - [ ] 本地开发地址可进入首页，并能从主导航进入所有已实现的平台模块。
  - [ ] 首页、创作页、画布页、工作流页、模板库、画布广场和素材库各有可见的页面状态与空/加载/错误/成功状态。
  - [ ] 新建画布、创建工作流、模板复制、素材筛选、搜索、收藏/发布演示等核心操作有可见反馈且状态可回退。
  - [ ] 画布工作区支持节点添加、移动、连线或删除的本地演示；工作流支持步骤配置和执行状态演示。
  - [ ] 页面在桌面和 390px 左右窄屏下无主要内容遮挡，侧栏可折叠或转为移动导航。
  - [ ] 不需要登录、密钥或外部 API 即可启动和演示；真实接口接入单独列为后续任务。

## 设计（Design）

- 方案：使用 Vite + React + TypeScript，以路由和领域模块组织页面；演示数据本地维护，组件按产品区域拆分，先建立与真实接口无关的 UI 状态层。
- 视觉：浅色工作台背景、深色文字、蓝色主按钮与选中态，窄边框和低圆角卡片；保留参考产品的工具型密度，不做营销落地页。
- 交互：主创作按钮进入本地工作区；模板、广场和素材使用本地搜索/筛选/分页；画布与工作流使用可序列化的本地状态；主题切换保存到 `localStorage`；未实现的 AI 任务显示演示状态。
- 涉及模块：`src/app/`、`src/components/`、`src/features/creator/`、`src/features/canvas/`、`src/features/workflow/`、`src/features/library/`、`src/features/assets/`、`src/features/account/`、`src/data/`、`src/styles/`。
- 备选方案与取舍：用户已确认首版使用完整前端 + 本地模拟数据；真实接口与服务端不作为当前交付依赖。这样可先完整验收页面、状态和交互，再按域接入服务。
- 证据边界：公开静态资源已验证路由 `/home`、`/aigc-creator`、`/aigc-canvas`、`/workflow`、`/aigc-template-library`、`/aigc-canvas-market`、`/aigc-assets` 与对应接口命名；登录态精确布局和用户专属数据需 Safari 权限恢复后核对。
