# 首页复刻 Spec

## 需求（Requirements）

- 背景：参考站是“超级编导”AI 内容创作平台，公开资源显示它包含无限画布、工作流、创意模板库和画布广场等入口。
- 目标：搭建一个本地可运行的首页前端原型，保留工作台的密度、蓝色主色和创作导向。
- 范围：桌面优先，同时适配窄屏；首页导航、欢迎/创作区、模板入口、最近项目、画布/工作流快捷入口、主题切换和本地演示反馈。
- 验收标准：
  - [ ] 本地开发地址加载后，首屏能看到品牌标识、主导航、主要创作入口和模板/项目内容。
  - [ ] 点击“新建画布”或同类主按钮会显示可见的创建反馈或进入本地演示工作区。
  - [ ] 模板分类/搜索能更新展示结果，并能恢复全部结果。
  - [ ] 页面在桌面和 390px 左右窄屏下无主要内容遮挡，侧栏可折叠或转为移动导航。
  - [ ] 不需要登录、密钥或外部 API 即可启动和演示。

## 设计（Design）

- 方案：使用 Vite + React + TypeScript（或仓库实际选择的等价轻量前端栈），以单页状态组织首页；演示数据本地维护，组件按页面区域拆分。
- 视觉：浅色工作台背景、深色文字、蓝色主按钮与选中态，窄边框和低圆角卡片；保留参考产品的工具型密度，不做营销落地页。
- 交互：主创作按钮触发本地 toast/工作区预览；模板搜索与分类使用本地过滤；主题切换保存到 `localStorage`；未实现的 AI 功能明确显示演示状态。
- 涉及模块：`src/App.*`、`src/components/`、`src/data/`、`src/styles/`、`package.json`。
- 备选方案与取舍：首版不复刻真实画布编辑器和服务端接口，以可验证的首页体验控制范围；真实接口留到后续独立 spec。
- 证据边界：公开静态资源已验证模块名称与蓝色品牌基线；登录态精确布局未知，需以用户提供的截图或 Safari 权限恢复后校准。
