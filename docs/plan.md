# 项目计划

## 项目目标

- **一句话目标**：在本地搭建一个与“超级编导”首页信息架构和视觉气质一致、可操作的前端原型。
- **成功判据**：用户打开本地地址后能看到首页导航、创作入口、模板/画布入口和最近项目区，并能完成主要筛选、切换和创建演示交互。
- **当前阶段**：探索

## 非目标

- 不接入参考站的账号、支付、真实 AI 生成和素材上传后端。
- 不复制参考站的用户数据、私有资源或服务端接口。

## 里程碑

| # | 里程碑 | 目标 | 退出条件（可判定） | 关联 spec | 状态 |
|---|---|---|---|---|---|
| M1 | 首页原型 | 建立前端脚手架与首页视觉结构 | `npm run dev` 可打开首页；导航、创作入口、模板区可见 | `docs/specs/home-replica.md` | 进行中 |
| M2 | 交互闭环 | 让首页关键入口产生可见反馈 | 新建画布、模板筛选、主题切换等操作可在浏览器中完成 | `docs/specs/home-replica.md` | 未开始 |
| M3 | 交付验证 | 校验构建与响应式布局 | `npm run build` 通过，桌面与窄屏布局无明显遮挡 | `docs/specs/home-replica.md` | 未开始 |

## 当前焦点

- **正在做**：M1 前的范围确认
- **下一个里程碑的前置条件**：用户确认首页复刻 spec，并提供 Safari 首页截图或开启 Safari 自动化权限以校准细节
- **阻塞项**：无法读取 Safari 当前页面；公开资源可确认产品模块，但不能确认登录态首页的精确布局

## 风险与依赖

| 风险 | 影响 | 应对 | 触发信号 |
|---|---|---|---|
| 登录态首页与公开静态资源的默认路由不同 | 视觉复刻偏差 | 以用户截图校准，首版保留可调整的布局 token | 用户截图与静态资源推断冲突 |
| 未接入真实后端 | 生成按钮只能演示 | 所有异步操作显示本地状态与示例结果 | 用户要求真实生成或数据同步 |
